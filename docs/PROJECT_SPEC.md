# 当前项目规格

## 产品和范围

VV `1.2.0` 是 Chrome 和 Edge 的 Manifest V3 浏览器扩展，最低 Chrome 版本为 120。正式交付目录是 `dist`。当前运行程序包含网页适配器、扩展界面、后台任务管理和模型接口。

普通测验处理单选、多选和填空，支持逐题翻页、一页多题、必要题目图片以及截图坐标操作。运行方式固定为全自动；用户可以暂停、继续、停止或清除任务。中文和 English 设置同步到扩展弹窗、设置页及任务面板。

课程功能覆盖学习通、知到共享课和知到 AI 智慧课程中的视频、视频弹题和关联课时或章节测验。文档、独立作业、讨论和期末考试属于范围外任务。知到 AI 另有独立知识点练习入口。

功能是否能够用于某个具体页面，取决于实际页面结构、授权和控件是否通过校验。未知结构显示明确识别错误。当前真实课程验收事项见 [待处理事项](WORK_CHECKPOINT.md)。

## 模型和调用额度

用户在弹窗选择 Provider 和模型，任务保存启动时的选择。接口类型支持 OpenAI 兼容、Google Gemini 原生和 Anthropic 原生。图片输入及原生网页搜索由 Provider 设置授权，并检查实际所需能力。

响应模型名称可以与请求模型名称不同；名称差异不会拒绝有效答案、触发重试或切换模型。正常返回的答案不确定且能够执行时，采用最佳候选并标记猜答。服务错误、无效答案结构和提交结果未知分别处理。

每场普通测验和每门课程分别维护调用预算，默认上限为 300。课程加载目录与运行共用预算。识别、求解、重试及计入额度的搜索均计费；预算预留在请求前保存。预算耗尽时暂停受影响任务。

## 动作和完成条件

模型只引用当前观察中提供的题目、选项、填空或元素 ID。本地程序在操作前检查会话、目标归属、唯一性、页面版本及取消信号。模型输出不能直接执行脚本、选择器或任意网页操作。

普通测验在填写后读取实际选中状态或字段值，提交后核对反馈，翻页后重新读取题目。已经评分的题目先检查结果和正常重答入口。首次答案后默认最多重试两次，同时受网页实际剩余次数限制。

课程目录展开、分页和延迟加载结束后确定范围，默认选择全部未完成课时，也可选择章节或课时。每个课时发现实际视频、测验及范围外资源，并按照前置条件处理。同一门课程和班级串行运行。

视频任务完成采用平台学习记录；媒体结束单独读取。测验任务完成采用实际提交结果，平台要求及格时还要确认及格。已有有效记录直接采用。全部选定任务确认完成才显示完成，未完成任务保留具体原因。

## 后台运行和异常

后台播放使用浏览器内部悬停与正常播放器控件，依据实际播放位置增长确认运行。视频静音，保留用户外部 Global Speed 设置并展示实际倍速。加速尚未生效时使用当前速度播放；页面明确禁止倍速时提示调整。

正常页面导航等待 30 秒，没有有效播放进展等待 120 秒，平台记录等待 120 秒并允许一次正常返回目录核验。局部播放、结构识别或记录超时保留任务失败原因，继续没有前置阻碍的其他资源及课时，结束前再核验一次。仍未完成时显示“需要处理”。

登录失效、验证码、权限不足、预算耗尽和持续模型服务失败暂停受影响任务。暂停和停止取消在途请求并暂停视频，迟到回复不能操作页面。关闭控制面板后后台继续运行。

## 保存和并发

课程身份、选定范围、资源发现状态、结果、预算、重试次数和未确认操作保存于本地。实际提交前保存操作状态。浏览器重启后展示可恢复课程；用户登录并点击继续后，重新核验课程、班级、资源和已有提交记录。

统一任务面板默认最多同时运行 3 场，可设置为 1 至 10 场，超出上限按照启动顺序排队。不同任务分别维护页面、模型请求、预算和动作状态；同一课程和班级保持串行。
