# 待处理事项

当前待处理工作是用户对正式课程功能的真实验收与反馈。验收方法见 [验证要求](verification.md)。

1. 学习通、知到共享课和知到 AI 智慧课程的不同课程页面：完整目录、分页、延迟加载、多资源课时及连续推进。
2. 鼠标离开、切换标签和应用时的后台连续播放；Global Speed 设置、实际媒体倍速和平台任务记录分别确认。
3. 视频弹题、关联课时及章节测验、已有结果采用、及格重答和平台剩余次数限制。
4. 暂停及停止时取消请求和暂停视频；未知提交保护；浏览器重启、重新登录后核验身份、资源和已有记录再继续。
5. 多课程并发时页面、动作和预算隔离，同一课程和班级串行；请求与响应模型名称不同的有效回复继续运行。

收到实际失败反馈后，核对当前构建、页面和原因，修复相关源码并交付同一 `dist`。已确认通过或已解决的事项从本文件移除。
