# 快照带来的网页识别改进能否长期保留

## 结论

可以把经过本地验证的网页结构经验保存下来，减少以后重复识别的成本。不能把一次快照识别出的坐标永久沿用，也不能声称本地程序因发送快照而永久训练了模型。

目前已实施的是首次语义快照帮助找题、同场结构提示和同场像素验证复用；Canvas首次整页上下文与局部定位见 `CANVAS_ACCEPTANCE_20261005.md`。这些改善已写进源码，但当前识别缓存仍随会话结束释放，没有实现跨会话自动学习。

## 可行的持久化方案（待实现）

1. 保存网站来源、页面模板特征、题根/控件的结构关系、支持的题型及规则版本；只采纳真实观察、本地映射验证及执行后验证全部成功的样本。
2. 不保存密钥、登录凭据、用户输入、答案、成绩、原图或固定屏幕坐标。临时ID需转换为结构关系，页面URL参数中的身份信息不能写入规则。
3. 下次仍默认发送首次快照，比较当前页面与旧规则。旧规则只作为候选结构提示；题根、选项、禁用状态、题目归属和网站权限必须在当前页面重新确认。
4. 模板、框架、缩放或题型改变时立即回退重新识别；模型低置信度或本地验证失败不写入规则，失败规则撤销。Canvas坐标始终由最新图片重新读取并校验。
5. 设置有效期、规则版本、来源说明和一键停用/重置；重置文件也按项目要求移入回收站。按网站隔离规则，不能把某网站结构推广到所有网站。

## 验证后才能启用

用未参与规则生成的页面与新会话验证：减少结构识别调用，保持答案/提交/完成判定正确，页面改版能安全回退，外部计时器和最终成绩没有遗漏。增加自动积累规则前，应先交付可查看、可撤销的结构规则缓存。

当前没有把它计入已完成验收，也没有启用隐藏的跨会话学习。
