## 本地检查覆盖

默认检查集合由 `vitest.logic.config.ts` 指定，包含答案与动作计划、分批、预算预留、计时、Provider 配置、课程范围、资源依赖、局部失败后的可执行条件、完成判定、框架投影、地址身份、取消保护和界面语言。

这些检查采用纯逻辑、数据转换、真实 Promise 及 AbortController。它们不证明真实平台已经接受视频记录、测验提交，也不证明所有浏览器页面结构已通过验收。检查数据、脚本存在或模型调用数量不能单独作为真实课程完成证据。

## 真实验收

当前课程验收由用户操作并反馈，具体待处理项目见 [待处理事项](WORK_CHECKPOINT.md)。使用当前正式构建、实际课程页面、用户选择的模型和公开平台记录，覆盖以下情形：

| 项目 | 应取得的实际证据 |
| --- | --- |
| 三类课程页面及不同课程 | 实际课程和班级、完整目录、范围、分页及延迟加载结果 |
| 多资源课时和连续推进 | 全部资源发现、前置条件、已完成记录采用及下一课时 |
| 后台播放 | 鼠标离开、切换标签和应用时播放位置继续增长；实际平台记录确认 |
| 外部倍速插件 | 插件设置与实际媒体倍速、平台记录分别确认 |
| 弹题和关联测验 | 实际选择、填写、提交、结果、重答次数和恢复播放 |
| 局部失败 | 原因保留，其他独立任务继续，结束复核仍依据实际记录 |
| 暂停、停止和重启 | 请求取消、视频暂停、迟到动作被阻止；重新登录后核验已有结果 |
| 多课程和预算 | 各任务页面、动作和调用费用隔离，同一课程和班级串行 |
| 模型名称差异 | 请求名称与响应名称不同的有效回复继续处理 |

普通测验变更按照受影响功能验证实际题目、选中状态、填空内容、重答入口、翻页、提交及网站结果。截图操作同时检查实际画面、目标范围和页面变化后的拒绝行为。

真实验收不采用模拟网站、模拟模型、隐藏答案、伪造时间、评分或平台进度作为通过证据。已有记录先核对，未知提交保持断点，不能为重新测试重复提交已确认结果。
