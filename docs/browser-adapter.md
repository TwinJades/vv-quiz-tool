# 网页识别与操作

## 三种输入方式

| 模式 | 实际输入和操作依据 |
| --- | --- |
| `structured` | 网页组件提取题干、选项、填空及必要图片，模型返回结构化答案 |
| `semantic_snapshot` | 首次发送清洗后的实际可见页面文字和元素结构，模型识别题目与控件，本地核验后进入答题 |
| `visual_snapshot` | 发送当前可见视口截图，识别题目、目标区域及坐标，经截图和目标校验后操作 |

语义快照包含当前可见文本、元素关系、控件状态和临时元素 ID。脚本、样式、密码字段和隐藏答案不能作为题目输入。模型只引用观察中的 ID，本地映射对应实际节点。

截图识别需要 Provider 图片授权及能力。Canvas 等特殊画面通过 `VisualWebAdapter` 和 `VisualTransport` 处理；坐标使用明确的 `normalized_1000` 单位，并结合实际裁剪区域、滚动位置、视口及缩放进行转换。

## 页面组件

`DomWebAdapter` 处理实际网页控件和同一页面中的多题。`SemanticDomMapping` 维护观察中的元素 ID、实际节点、文本和状态关系。网页读取包含已授权框架；题目所在框架需要能够唯一确认。

项目包含学习通目录、课程、播放器及章节测验组件，知到目录、导航、视频、知识点练习及结果组件，以及 H5P 和 SurveyJS 的结果读取。内置组件仍使用同一答案、目标和操作核验要求。

学习通字体编码题目使用实际题目截图取得可读题干和选项，作答目标继续通过实际控件绑定。结构相同的后续题目可以复用本场已核验的识别结构；页面结构或控件变化后重新观察。

## 操作前检查

每次操作检查当前会话、操作版本和取消信号。目标必须存在、可用、唯一，属于当前题目或课程资源，页面版本及元素内容必须与当前观察一致。导航、节点替换、目标身份变化或用户操作会使旧目标失效。

程序依据有效答案生成固定类型的动作。模型不能提供任意选择器、脚本或自由动作。操作后重新读取实际选中状态、填空内容、反馈、结果和下一题状态。

## 课程框架

`SemanticCoursePage` 读取当前课程身份和实际目录、资源及控件。`CourseTabPlatform` 负责目录展开、分页、滚动加载和运行时重新定位入口。导航结束后等待有效 DOM，重新核验课程、班级和课时。

跨源资源框架通过父页面实际嵌入的地址、后代框架关系及当前文档身份确定。子框架识别使用已核验的父课程上下文。播放器悬停点和测验截图区域通过 `frame-projection.ts` 转换为目标标签坐标。

同源媒体和框架通过实际页面读取；跨源媒体使用绑定后的子框架。缺少权限、框架不唯一或身份变化时停止对应动作。

## 播放和输入交接

后台播放使用浏览器内部输入维持正常悬停，读取实际媒体位置确认持续播放。视频静音，倍速来自外部 Global Speed。实际速度、缓冲、暂停、回看和结束分别显示或参与核验。

弹题出现后解除视频悬停并交给答题输入，弹题解除后恢复视频。暂停和停止取消输入授权并暂停实际媒体。页面可见性、时间和平台进度保持实际状态。

课程观察对播放器计时和字幕变化使用缓存；目录、资源、控件、弹题和完成记录变化重新识别。未知页面保留具体错误，不据此生成完成状态。
