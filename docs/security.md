# 安全、隐私与信任边界

## 1. 安全目标

VV 自动答题工具必须把网页、应用界面、模型输出和外部 Provider 都视为不可信输入。系统的核心目标是：

- 模型只能返回受限的结构化答案，不能获得任意执行权限。
- 动作只能作用于当前 QuizSession 已观察和授权的平台目标。
- Prompt Injection、页面变化或模型幻觉不能直接变成点击、输入或导航指令。
- 用户密钥、Provider 配置和题目图片只在本地按需处理。
- 不建设项目服务器，不收集遥测，不永久保存题目或答案。

## 2. 信任边界

| 区域 | 信任级别 | 说明 |
|---|---|---|
| VV 核心协议与策略 | 可信 | 负责校验、调度、能力限制和状态机 |
| PlatformAdapter | 有限可信 | 只能在声明能力和当前会话范围内观察与执行 |
| 页面、Accessibility Tree、UIA Tree、截图 | 不可信 | 可能包含恶意指令、伪造控件或动态变化 |
| 模型输出 | 不可信 | 必须通过结构和语义校验 |
| Vercel AI SDK 与 Provider | 外部依赖 | 只允许完成模型调用和声明能力 |
| Provider 原生网页搜索 | 外部能力 | 由模型按需使用，不受 VV 独立搜索层控制 |
| 用户本地配置 | 敏感数据 | 只在本地保存并按最小范围使用 |

## 3. 最小权限

### 3.1 浏览器权限

- 首发只申请 Chrome/Edge 实际需要的权限。
- 站点访问权限按来源管理，不默认覆盖所有网站。
- 当前标签页导航到已授权来源时，会话可以跟随。
- 打开新的来源前必须请求相应权限；未授权时暂停。
- 一个标签页的会话不能读写另一个未绑定标签页。

### 3.2 Android 与 Windows

- Android Accessibility 和 Windows UIA 适配器上线时必须清楚展示所需系统权限。
- 适配器只能操作当前明确绑定的应用和会话。
- 能力声明不能把未验证或受限制的系统动作标记为可用。

## 4. Prompt Injection 防护

页面文本、图片内容、控件标签、搜索结果和错误反馈都只是题目数据或外部证据，不是系统指令。

防护要求：

- 系统提示明确限定模型任务为回答给定题目。
- 发送给模型的数据与 VV 内部控制指令分区表示。
- 模型只能返回 AnswerResult 允许的字段。
- 不接受模型返回的脚本、选择器、URL、终端命令或自由动作序列。
- AnswerValidator 只允许引用当前 QuestionFrame 中存在的语义 ID。
- 页面中要求泄露密钥、修改配置、访问其他标签或绕过限制的内容一律忽略。
- Provider 原生搜索结果同样视为不可信内容，不能扩大模型权限。

## 5. 动作安全

### 5.1 目标绑定

LocatorMap 不发送给模型。模型选择的是题目语义 ID，由本地适配器映射为实际控件。

执行前必须确认：

- 会话、标签页或应用身份没有改变。
- 页面观察版本与答案生成时兼容。
- 目标仍然属于当前题目。
- 动作类型与平台声明能力一致。
- 提交、翻页等高影响动作满足当前运行策略。

### 5.2 页面变化与竞态

DOM 重绘、页面导航、滚动、缩放、窗口变化或用户操作都可能使旧目标失效。发现变化时必须重新观察，不得盲目重放旧动作。

### 5.3 视觉坐标

坐标点击只用于语义目标不可获得的视觉页面。执行前需检查截图版本、目标区域、窗口尺寸、缩放和滚动位置；执行后必须 VERIFY。无法确认时暂停，不扩大点击范围进行试探。

## 6. 模型权限

模型无权：

- 直接调用 DOM、Accessibility、UIA 或系统输入接口。
- 执行代码、脚本、命令或浏览器扩展 API。
- 读取 API Key、Provider 配置或其他会话内容。
- 自行改变运行模式、并发限制、调用上限或重试策略。
- 绕过验证码、登录、访问控制、监考或站点技术阻断。

模型可以在用户启用且 Provider 支持时按需调用 Provider 原生网页搜索。VV 不向模型提供独立通用浏览器、爬虫或搜索服务。

## 7. Provider 与密钥

- API Key、Provider 配置、模型选择和图片授权只保存在本地。
- 界面和日志不得显示完整密钥。
- API Key 与 Provider Profile 分开存储，不在 Provider 列表中显示。
- 删除 Provider 时同时删除其本地敏感配置。
- 优先使用 HTTPS；本地开发端点必须由用户明确配置。
- 每场测验只使用用户选定的 Provider 和模型，不能静默切换。
- Provider 不可用时暂停，不把题目发送给其他 Provider。

## 8. 数据最小化

当前版本不保存：

- 题库或答案历史。
- 题目截图和原始图片副本。
- 永久运行记录或详细模型响应历史。
- 用户行为统计、错误遥测或分析数据。
- 用于训练或微调的数据集。

运行中只保留完成当前会话所需的临时数据。会话结束仅显示临时总结；关闭或清除后释放。

图片只在当前题确实需要视觉理解、用户已授权且选定模型支持图片时发送。没有图片授权时不得上传图片。

## 9. 网络边界

VV 不建设项目服务器。网络请求仅限于：

- 用户配置的模型 Provider。
- Provider 自身提供的模型列表接口。
- 用户启用后由 Provider 执行的原生网页搜索。
- GitHub 上的源码、安装包和用户主动发起的更新获取。

系统不自动上传错误、统计、题目、截图、运行总结或设备信息。

## 10. 多会话隔离

每个 QuizSession 独立维护：

- 平台目标和权限范围。
- Provider、模型和调用预算。
- 题目、定位、答案和验证状态。
- 重试计数、计时器和运行模式。

任何跨会话复用都必须是无敏感状态的核心逻辑。题目内容、图片、定位和答案不能流入其他会话。

## 11. 产品边界

VV 不按教育、练习、测评或其他用途对用户分类，但产品本身不提供以下能力：

- 绕过验证码、访问控制、登录或权限检查。
- 规避监考、反自动化或站点明确的技术阻断。
- 突破站点不允许的重试、提交或访问限制。
- 隐藏自身操作以对抗安全检测。

遇到这些阻断时，两种运行模式都必须暂停并提示用户。

## 12. 依赖与发布

- 第三方依赖应锁定兼容范围并定期更新。
- Vercel AI SDK 及 Provider 适配层升级必须验证结构化输出、图片输入和工具能力映射未发生破坏性变化。
- Chrome 与 Edge 安装包必须能追溯到对应源码版本。
- 不在仓库、示例配置、构建产物或问题报告中包含真实密钥。

## 13. 发布前安全检查

- 模型输出无法直接触发自由动作。
- 恶意题目文本不能改变系统策略或泄露密钥。
- 坐标动作在页面变化后会被拒绝或重新观察。
- 跨标签页、跨应用和跨会话动作被隔离。
- Provider 配置和 API Key 仅保存在本地。
- 图片未获授权时不会发送。
- 所有网络目标都能由用户配置或明确识别。
- 不产生题库、答案历史、截图存档、永久日志或遥测。
- 验证码、登录失效、权限不足和监考阻断会暂停。
