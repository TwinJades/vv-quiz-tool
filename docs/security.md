# 数据与权限

## 浏览器权限

Manifest 使用 `activeTab`、`debugger`、`notifications`、`scripting`、`storage` 和 `webNavigation`。网站与 Provider 来源属于可选权限，由用户操作时申请。目标页面或资源框架未授权时暂停对应操作。

`debugger` 用于绑定标签页的截图、坐标输入和正常悬停；浏览器可能显示调试连接提示。通知用于需要用户处理的任务状态。扩展没有获得其他应用的桌面操作权限。

## 本地保存

| 数据 | 保存位置和用途 |
| --- | --- |
| Provider 名称、接口、模型和能力 | `chrome.storage.local`，供当前浏览器配置使用 |
| API Key | `chrome.storage.local` 中的独立密钥引用，不显示在 Provider 列表 |
| 界面语言、模型偏好和并发上限 | `chrome.storage.local` |
| 普通测验运行快照 | `chrome.storage.session`，保存当前浏览器会话中的恢复状态 |
| 课程准备会话和范围 | `chrome.storage.local`，保存加载配置、目录及共用预算 |
| 课程恢复记录 | `chrome.storage.local`，保存身份、范围、结果、预算、重试及未确认操作 |

课程恢复记录包含子测验的答案及重试状态，用于核验后恢复当前任务。它随已保存课程记录管理，可以通过任务面板清除。临时媒体句柄和实际 DOM 节点在会话中使用，课程恢复时重新读取实际页面。

密钥采用浏览器本地存储，当前源码没有额外的密钥加密层。删除 Provider 时删除对应秘密配置；正在被任务使用的 Provider 受到检查保护。用户凭据和浏览器资料不纳入项目仓库。

## 发往模型服务的数据

按当前任务发送题目文字、选项、填写字段、需要的图片、已授权截图和搜索内容。截图模式发送当前可见网页画面；课程识别发送实际页面结构与公开身份，恢复地址清理敏感参数并保留正常定位参数。

API Key 用于服务认证，不作为题目输入。定位映射、实际网页节点和浏览器权限不进入模型请求。页面、图片、反馈、搜索结果和模型输出均作为不可信内容处理。

Provider 如何保存或处理请求由所选服务决定。VV 没有项目模型服务器、遥测或自动上传到维护者的运行记录。

## 模型与动作限制

模型只能引用当前观察中允许的题目、选项、填空及元素 ID。答案经过结构和目标校验后，本地程序生成固定动作。模型输出不作为脚本、HTML、选择器或终端命令执行。

操作前核验会话、网页或框架、目标归属、唯一性、文档版本及取消信号。暂停、停止、用户操作和页面变化撤销旧动作授权；迟到回复不能继续操作。

图片输入须经用户授权且模型支持。网页搜索只使用用户允许且当前接口已接入的原生能力。不同任务的页面、请求、预算和答案分别管理。

## 平台阻断和结果

登录失效、验证码、权限缺失、监考提示和服务持续失败暂停相关任务。程序使用正常页面控件和公开结果，不读取隐藏答案，也不伪造焦点、可见性、播放时间、成绩或平台记录。

提交结果未知时保存断点。完成判定来自实际平台记录和结果，恢复先核对已有记录，不能依据模型回复或旧缓存直接显示完成。
