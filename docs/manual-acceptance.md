## 启动与操作

1. 双击仓库根目录的 `Start-VV-Acceptance.cmd`，保持命令窗口打开。首次启动会构建当前源码，并用独立的 Chrome for Testing 配置打开本地记录页和默认测试网站 `https://h5p.org/node/8777`。如果之前由新版程序登记的同一测试浏览器仍开着，会自动重新连接；如果记录程序也还在运行，则直接打开它的记录页。连接现有浏览器时不重建或重载 VV、不修改模型偏好。
2. 在网站标签点浏览器工具栏的 **VV 自动答题** 扩展；若图标不在工具栏，先在扩展拼图菜单里固定它。确认 CPA Provider 和模型。只选 Gemini 3.8 Flash、Gemini 3.7 Flash 或 Gemini 3.1 Pro 系列 ID；优先 3.8，若本机 CPA 模型目录没有它则选 3.7，再选 3.1 Pro。记录页会显示当前目录中的允许模型及所选 ID。
3. 在 VV 弹窗中选“无人值守”和“允许快照”（新会话默认首次发送页面语义快照），模型调用上限可设为 60，点击“开始”并授予当前网站和必要 iframe 的权限。观察是否逐题作答并到网站结果页。
4. 在这个测试浏览器中任意打开网站、新建普通标签或普通窗口、从站内目录挑选题目，都会自动加入监视。无需从记录页的输入框进入。推荐入口显示在记录页的“推荐网站与自由选择”，下文也列出完整网址。
5. 切回记录页，在“当前网页标签”中选要保存的网站，并选择对应的 VV 会话；纯手动作答时选择“仅人工网站测试”。填写观察及最终成绩，点击“保存结果和网站截图”或“只保存文字结果”。截图时会将所选网站带到前台，确保有画面；之后可自行切回记录页。页面文字结果和截图都明确关联所选标签、会话和实际捕获网址。
6. 把记录页显示的**记录目录**告诉 Codex，之后可据此复核。保存结果后可点击“停止记录（保留浏览器）”；命令窗口会显示退出状态并等待按键，浏览器仍打开。报告位于项目内被 Git 忽略的 `.browser-regression-runtime/manual-reports/`。不要分享整个浏览器配置目录，它可能包含 CPA 密钥。

也可在记录页输入完整 HTTP/HTTPS 地址并点击“在测试浏览器打开”。每次会新开标签，保留以前的报告。没有 CPA 配置时，可在隔离浏览器的 VV 设置里配置。程序默认复用 `visible-retry-20260930` 隔离配置；也可设置 `VV_TEST_PROFILE` 为其他独立配置、`VV_TEST_BROWSER` 为 Chrome 可执行文件。若需显式接入已开放本机 CDP 的测试浏览器，可运行 `node scripts/manual-acceptance.mjs --attach-port=50739`（端口以实际启动参数为准）。

浏览器会另开标题为“VV 记录连接（请保留）”的设置标签供记录程序读取会话；请保留该标签，其他网站标签可随意关闭。若此连接标签关闭，记录页会显示连接错误，停止记录后重新双击启动即可。若 VV 提示缺少 Provider 网络权限，在 VV 设置中对 CPA 执行“刷新模型”，授予本地 CPA 地址权限，再回网站操作。程序使用本机 Node.js 24；全新启动还需要项目依赖和 Chrome for Testing，缺少时命令窗口显示原因并保持可读。

监视范围是**本程序连接的一个独立浏览器配置的全部普通网页窗口和 HTTP/HTTPS 标签**，不是电脑上的所有 Chrome/Edge 进程。浏览器内部页面不加入网站结果清单；无痕 VV 会话未纳入验证，请使用普通窗口。它会记录该配置中的网站标题及网址，因此请把这个浏览器用于验收。

## 记录内容与验收判定

- 程序用本机 CDP 枚举全部网页目标，通过 VV `VV_GET_SESSION` 查询所有浏览器标签的会话。已有网站权限时，仅额外读取网址和文档加载时间，将 VV 标签 ID 与 CDP 页面匹配；重复网址不会靠标签顺序猜测。未授予权限的网站仍列入网页清单，暂未关联的会话明确标记。VV 自己仍按原流程申请网站及 iframe 权限，记录器没有扩大扩展正式权限。
- 每两秒采样一次；`events.jsonl` 追加状态变化和开页、换页、关页事件。`report.json` 的 `schema=2`、`scope=browser`，`tabs` 保留各标签和导航历史，`sessions` 按 session_id 保留每次会话，结束后不覆盖此前测试。保存记录含 target_id、tab_id、session_id、实际页面 URL；截图文件名包含目标 ID。同标签重启 VV 形成独立会话。
- 会话达到 COMPLETE/PAUSED/FAILED/CANCELLED 时，自动保存该页面的文字成绩线索；用户按需保存截图及备注。只有 VV `COMPLETE` **并有整个活动终点的成绩证据**，才能判定自动整场通过。单题 Correct/1/1、部分题目 COMPLETE、暂停和取消均不能替代整场证据。纯人工保存的事件是 `mode=manual_site_only`。
- 全新启动可在扩展设置上下文中用既有密钥查询 CPA `/models` 并优先设置已配置且可用的许可模型；密钥不返回 Node、不写入报告。连接现有浏览器只显示既有模型目录，不访问 CPA 或改变偏好。程序不会启动 VV、自动答题或发起模型解题请求。
- 接入现有浏览器时，只能恢复扩展仍保留的最新会话。接入前已结束且被覆盖的会话应从原来的 `events.jsonl` 复核；相关旧目录列在 `legacy_report_directories`。两次采样之间极短的状态可能无法捕获。网页成绩提取仅是关键词线索，跨源 iframe 或特殊成绩界面可能需截图和人工备注补充。
- 同源码、配置、网站、模型且由 VV 完成全场时，人工操作入口可以用于核心功能验收。记录程序不会自动判定通过，需后续核对完整进度、网站终点及人工介入情况。
