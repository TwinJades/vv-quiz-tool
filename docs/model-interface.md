# 模型接口

## 配置和接口

`ProviderManager` 在浏览器本地保存 Provider 配置、模型目录和独立密钥引用。设置页支持 OpenAI 兼容、Google Gemini 原生和 Anthropic 原生接口，运行时使用对应的 Vercel AI SDK 适配器。

模型目录从实际接口读取；无法取得目录时，用户可以填写实际模型 ID。目录中的模型名称不证明它具备图片或搜索能力。任务启动时读取选择及授权，并检查当前操作所需能力。

任务使用用户选定的 Provider 和模型。请求名称与响应名称允许不同，有效回复按照内容及结构处理。接口错误不会自动切换到其他服务。活动会话使用的 Provider 受到配置和删除检查保护。

## 请求内容

`SolverProvider` 发送固定求解规则、明确作为不可信内容处理的题目数据、结构化输出要求及允许使用的原生搜索工具。课程识别请求发送当前实际页面观察，模型仅引用本次观察中的元素 ID。

本地 `LocatorMap`、实际节点、浏览器权限及密钥值不作为模型输入。题目图片通过临时媒体句柄读取；截图模式发送当前可见页面，学习通编码题目发送实际题目区域。图片请求要求授权和实际图片能力。

结构化输出使用 Zod 校验。答案必须对应当前题目、选项及填空 ID，拒绝额外、重复、未知或不匹配的答案。正常输出不确定且含有效可执行候选时标记猜答；没有可执行候选时暂停。

## 分批和能力

每个 Provider 的模型共用分批限制，默认每批最多 5 题、12000 内容估算单位和 4 张图片。用户可以调整；实际接口返回的输入上限继续限制请求大小。

正文和共享上下文按照 UTF-8 字节估算，图片另计估算费用。这个估算用于请求分批，实际模型计费取决于服务。超过单题或共享内容限制时报告原因，题目内容和关联 ID 保持完整。

原生网页搜索接入 OpenAI 兼容接口和 Anthropic 原生接口。OpenAI 兼容接口通过 Responses 搜索并使用 Chat Completions 求解；Anthropic 使用 SDK 原生搜索工具。Google 原生接口的搜索开关当前禁用。兼容服务是否提供所选搜索能力，以实际请求结果为准。

## 调用预算

每场测验、每门课程独立维护 `ModelCallBudget`，默认上限 300。目录识别、题目识别、答案、重试及搜索费用计入相同任务。课程准备会话与后续运行共用预算。

搜索请求预留模型调用和允许的搜索费用；实际未使用的费用在能够确认结果时释放。结果未知时保留预留费用。SDK 隐式重试关闭，程序显式请求和重试分别计数。预算不足时在发送前暂停。

## 错误和取消

| 情况 | 当前处理 |
| --- | --- |
| 网络和可重试服务错误 | 有限重试，每次请求计费，持续失败后暂停 |
| 身份认证、权限或模型不存在 | 显示原因并暂停，不显示密钥 |
| 能力或答案结构不匹配 | 拒绝当前输出，按该请求的校验与重试规则处理 |
| 正常答案不确定 | 使用通过本地校验的最佳候选并标记猜答 |
| 页面、题目或目标改变 | 拒绝旧操作，重新观察实际页面 |
| 预算不足 | 请求前暂停受影响任务 |
| 用户暂停、停止或页面关闭 | 取消请求，迟到回复不能操作页面 |

普通识别和求解路径的默认单次请求截止为 120 秒，课程结构识别使用较短截止。课程持续服务失败暂停受影响课程；提交结果未知先核对已有记录，不能通过新的求解掩盖未知提交。

## 源码入口

- `src/provider/provider-manager.ts`：本地配置、密钥引用和配置一致性。
- `src/provider/model-catalog.ts`：实际模型目录。
- `src/provider/provider-capabilities.ts`、`model-batch-policy.ts`：能力及分批限制。
- `src/provider/provider-runtime.ts`：SDK 接口和原生搜索工具。
- `src/provider/solver-provider.ts`：页面识别、题目求解、结构校验、请求截止及取消。
- `src/core/call-budget.ts`：预算预留、保存和结算。
