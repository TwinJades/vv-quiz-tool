# 课程运行

## 入口和范围

学习通、知到共享课和知到 AI 智慧课程使用“加载当前课程 → 选择本次范围 → 开始学习”。课程准备会话保存弹窗选定的 Provider、模型和预算，默认上限为 300，目录加载与运行共用预算。

目录展开、分页和滚动延迟加载结束后确认范围，默认选择全部未完成课时，也可以选择章节或课时。每个课时读取全部实际资源；视频、弹题和关联测验进入自动处理，文档、独立作业、讨论和期末考试列为范围外任务。独立知到知识点练习入口只处理选定练习。

实际课程、班级、章节和资源身份来自当前 DOM、公开地址及属性，不依赖固定课程编号或数量。目录和资源发现状态保存于断点。未知页面、资源未加载完整或公开身份不足时显示具体错误。

## 资源执行

`CourseOrchestrator` 按课时和资源的实际前置条件处理。同一课程和班级串行运行；不同课程按照统一任务队列的并发限制分别运行。单个资源失败时保留原因，继续没有前置阻碍的资源及其他课时。

已有完成状态先核验平台有效记录。视频结束、平台任务记录、测验提交及及格结果分别检查。范围外资源不生成完成记录。全部选定可处理任务确认完成才显示完成，存在未完成任务时显示“需要处理”。

## 视频和倍速

视频静音后使用正常播放器控件与浏览器内部悬停播放，以实际播放位置增长确认运行。跨框架控件转换为目标标签坐标，页面导航后重新绑定资源；媒体身份与当前资源一致才能继续操作。

Global Speed 由用户安装和设置，扩展界面提供安装入口。VV 保留其设置，显示实际媒体速度。加速尚未生效时按当前实际速度播放；平台明确禁止倍速时提示调整。暂停、缓冲、弹题和回看期间冻结剩余时间估算。

弹题出现时交接输入控制，处理解除后恢复视频。单个播放器尚未加载时，其他已经发现的独立资源保留可执行状态。

## 测验和提交

`CourseQuizService` 使用本门课程的模型及预算。正常返回的不确定答案只要结构和目标有效，就使用最佳候选并记录猜答。模型服务错误、答案结构无效和未知提交分开处理。

首次答案后默认最多重试两次，受平台实际剩余次数限制。每次重答先核对已有结果、及格要求和正常重答入口。平台要求回看时，通过实际回看控件确认位置回退和弹题解除，回看次数保存于断点。

实际提交前保存操作状态。结果未知时保留测验边界和子会话状态；恢复后先读取实际提交记录。已有有效结果直接采用，不能把未确认操作作为新尝试重复执行。

## 等待和异常

| 情况 | 当前等待和处理 |
| --- | --- |
| 正常页面导航 | 等待有效页面及身份，默认 30 秒 |
| 视频没有有效播放进展 | 最多等待 120 秒，保留当前资源失败原因 |
| 平台任务记录未确认 | 最多等待 120 秒，其间允许一次正常返回目录核验 |
| 局部结构或资源失败 | 保留具体原因，继续其他没有前置阻碍的任务 |
| 其他可执行任务结束 | 对局部异常任务再核验一次实际记录 |
| 登录、验证码、权限、预算或持续模型服务失败 | 暂停受影响课程 |

## 保存和恢复

本地持久保存课程身份、范围、资源发现状态、任务结果、预算、重答次数、回看次数及未确认操作。预算预留在请求前保存，提交操作状态在实际提交前保存。

浏览器重启后任务面板展示保存的课程。用户重新登录并点击继续，程序重新核验课程、班级、资源和已有提交记录；保存为完成的资源也要重新核验实际记录。

暂停和停止取消在途请求、撤销迟到动作并暂停实际视频。关闭弹窗或任务面板后会话继续。更改准备阶段 Provider、模型或预算后需要重新加载课程。

当前真实课程验收事项见 [待处理事项](WORK_CHECKPOINT.md)，检查方法见 [验证要求](verification.md)。
