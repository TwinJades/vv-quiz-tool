## 输入与边界

用户自行登录进入课程，在预览目录后明确选择范围。当前实现仅允许结构、身份、状态、规则和操作目标可可靠观察的页面；缺材料/结构时返回诊断，禁止猜测控件。目录导航和视频状态在本地处理，模型只处理当前弹题/测验。弹题与章节测验独立，课程共享预算与受限Gemini备选链。没有评分或重试规则的页面保持unknown，不推测不计分/无限重试。

预计时间由(duration-currentTime)/实际速度计算，冻结暂停/缓冲/弹题/失效状态。播放结束、任务点完成、测验提交及满足任务规则分别验证。进度等待上限120秒且只允许一次正常返回目录；无有效播放进展120秒暂停。提交结果未知先重读结果，不自动重交。范围外前置任务、考试和其他任务不自动操作。

## 页面材料（两平台各一门同课程）

1. 课程类型、考核/倍速/可见性/测验次数及及格规则。
2. 展开目录：已完成、进行中、未开始、锁定状态及视频-测验关系。
3. 视频页及展开倍速菜单：标题、时长、位置、禁用提示。
4. 弹题、正确/已有错误反馈、重试次数、回看提示与回退位置。
5. 视频结束及目录/学习进度前后对照。
6. 课时/章节测验规则、题目、提交确认、结果及目录状态。
7. 已有缓冲、可见性和网络异常；没有的状态注明未覆盖。

附浏览器、课程域名和路径、两个连续课时的首轮范围。可遮盖个人信息，不需要密码、Cookie、令牌或完整网络请求，不要求故意答错计分测验。

截图不足再检查可见目录节点身份/链接、播放器iframe及只读媒体属性、弹题边界、提交/结果/完成标记与导航权限。不读取隐藏答案或私有完成接口。
