## 输入与边界

用户自行登录进入课程，在预览目录后明确选择范围。当前实现仅允许结构、身份、状态、规则和操作目标可可靠观察的页面；缺材料/结构时返回诊断，禁止猜测控件。目录导航和视频状态在本地处理，模型只处理当前弹题/测验。弹题与章节测验独立，课程共享预算与受限Gemini备选链。没有评分或重试规则的页面保持unknown，不推测不计分/无限重试。

预计时间由(duration-currentTime)/实际速度计算，冻结暂停/缓冲/弹题/失效状态。播放结束、任务点完成、测验提交及满足任务规则分别验证。进度等待上限120秒且只允许一次正常返回目录；无有效播放进展120秒暂停。提交结果未知先重读结果，不自动重交。范围外前置任务、考试和其他任务不自动操作。
