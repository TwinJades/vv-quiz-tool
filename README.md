# VV 自动答题工具

VV 是 Chrome 和 Edge 的浏览器扩展，当前版本为 **1.2.0**。你打开网页、登录网站并选择模型后，VV 可以读取题目、填写答案、提交和翻页。学习通和知到课程可以选择课时，让 VV 播放视频、处理弹题和关联测验，再继续下一课时。

## 可以做什么

- 处理单选、多选和填空，包括一页多题、逐题翻页以及图片题目。
- 使用你选择的模型服务答题。模型支持并且你允许时，可以读取题目图片、使用服务自带的网页搜索。
- 同时处理多个网页，在“所有任务”中查看进度、调整同时运行的数量。
- 随时暂停、继续或停止。关闭扩展弹窗后，任务继续运行。
- 在学习通、知到共享课和知到 AI 智慧课程中处理视频、视频弹题及关联测验。文档、独立作业、讨论和期末考试需要你处理。
- 保存课程进度。重启浏览器后，登录课程网站，在“所有任务”中打开已保存的课程并点击继续。

答案由模型生成，可能答错。课程功能仍有真实课程验收项目；具体页面无法识别、提交结果不明确或平台没有确认完成时，VV 会显示原因并保留任务状态。

## 安装

1. 找到本项目的 `dist` 文件夹。本机交付位置是 `D:\Codex工作区\vv-quiz-tool\dist`。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展”，选择 `dist` 文件夹。
4. 在浏览器工具栏的扩展菜单中找到 VV，可以将它固定到工具栏。

更新扩展后，在扩展管理页面点击 VV 的重新加载按钮。保留原来的扩展和安装目录，就能继续使用已有配置。

## 配置模型

点击 VV 弹窗右上角的设置按钮，选择“新建配置”。设置页中的 **Provider** 就是你使用的模型服务。

1. 填写显示名称、接口类型、服务地址和 API Key。这些内容由你的模型服务提供。
2. 保存配置。VV 会尝试读取可用模型；读取失败时，可以在“模型 ID”中每行填写一个模型名称。
3. 需要处理图片题时，开启“允许此 Provider 图片输入”，并选择支持图片的模型。题目图片会发送到这项模型服务；截图模式发送当前可见网页画面。
4. 需要搜索时，开启“允许此 Provider 原生网页搜索”。接口不支持时，设置页会说明原因。

VV 支持 OpenAI 兼容接口、Google Gemini 原生接口和 Anthropic 原生接口。接口能否提供所选模型和功能，取决于你使用的服务。

## 自动答题

1. 在网站打开需要处理的测验，并完成登录。
2. 打开 VV，选择 Provider、模型和调用上限，默认上限为 300。
3. 选择模型输入方式，然后点击“启动当前测验”。首次使用某个网站或模型服务时，按照浏览器提示允许访问。

| 输入方式 | 什么时候使用 |
| --- | --- |
| 快照模式 | 默认选择。让模型读取页面上的文字、选项和按钮。 |
| 截图模式 | 题目主要在图片或特殊画面中。需要开启图片输入，浏览器可能显示调试连接提示。 |
| 仅结构化数据 | 网页题干和控件已经能被 VV 直接识别时使用。 |

调用上限统计模型请求以及计入额度的搜索，识别和重试也会消耗额度。额度不足时任务暂停。答错后可以在网页允许的次数内重试，默认最多重试两次。已经评分的题目需要网站提供重答入口。

## 学习通和知到课程

1. 登录课程网站，打开要学习的课程。
2. 在 VV 中选择模型，展开“学习通／知到课程学习”，点击“加载当前课程”。
3. 等待目录加载完成，选择全部未完成课时、某个章节或某个课时。
4. 点击“开始学习”。加载目录和后续学习共用这门课程的调用额度。

VV 会静音播放视频，显示当前资源、实际倍速和平台记录。视频播放结束后，还要等平台确认学习记录，才能完成对应任务。测验需要及格时，会检查结果并在允许的次数内重答。部分资源失败时，VV 保留原因并继续处理其他能够进行的任务。

视频加速需要你自行安装并设置 **Global Speed**，安装入口在课程区域中。VV 显示视频当前的实际速度；显示 1 倍时，视频就按 1 倍播放。

只处理知到 AI 知识点练习时，可以使用“仅加载知到知识点练习”。这个入口处理所选知识点的练习。

## 暂停、恢复和问题提示

“暂停”保留当前状态，“继续”重新检查网页后恢复，“停止”结束任务。课程重启恢复需要你先重新登录。提交结果没有确认时，先检查网站上的已有结果，再点击继续，避免重复提交。

遇到验证码、登录失效、权限不足、模型服务错误或额度耗尽时，按照 VV 显示的原因处理。页面结构无法识别时，记录当前网址、操作步骤和错误文字，交给项目维护者检查。技术详情可以在提示旁展开查看。

## 配置和数据

模型配置、API Key 和课程恢复状态保存在当前浏览器本地。课程恢复状态包含课程、范围、结果、额度，以及恢复答题所需的状态；可以在任务面板中清除已保存的课程。

题目文字、必要图片和允许的搜索内容会发送到你选择的模型服务，服务如何处理这些数据由它决定。VV 没有自己的模型服务器，也不会自动向维护者上传使用记录。
